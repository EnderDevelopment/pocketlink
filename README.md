# Minecraft Phone Plugin

PocketLink is a Minecraft phone plugin that adds a pocket phone item, an inventory-based contacts app, and player-to-player teleport requests. Players can open the phone with `/phone` or by right-clicking the phone item, browse online contacts, and let the recipient accept or deny a teleport request.

## Install

1. Use a Paper server running Minecraft 1.21.11 or a compatible version, with Java 21.
2. Place the PocketLink plugin JAR in the server's `plugins` directory.
3. Start or restart the server.

## Use

1. Run `/phone give` to add a phone to your inventory.
2. Right-click the phone or run `/phone` to open it.
3. Select Contacts and click an online player's head to send a teleport request.
4. The recipient runs `/tpaccept` to teleport the requester to them, or `/tpdeny` to reject the request. Requests expire after 60 seconds.
